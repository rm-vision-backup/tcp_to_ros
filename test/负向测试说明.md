# tcp-to-ros 负向测试说明

## 目标

- 验证协议拒绝路径；
- 验证 `command_id` 去重缓存；
- 验证 `HOLD` 对活动任务的打断逻辑。

## 前提

先启动：

```bash
cd /home/ub20tg/catkin_swarm6-2
source ~/.bashrc
source /home/ub20tg/catkin_swarm6-2/devel/setup.bash
roslaunch tcp_to_ros tcp_to_ros_mock.launch
```

## 测试脚本

另开终端执行：

```bash
cd /home/ub20tg/catkin_swarm6-2
source ~/.bashrc
source /home/ub20tg/catkin_swarm6-2/devel/setup.bash

python3 src/tcp_to_ros/test/test_wrong_group.py
python3 src/tcp_to_ros/test/test_duplicate_command.py
python3 src/tcp_to_ros/test/test_hold_interrupt.py
```

## 预期结果

### 1. `test_wrong_group.py`

预期：

- 脚本退出码为 `0`
- 返回 `FAILED`
- `error_code=WRONG_GROUP`

### 2. `test_duplicate_command.py`

预期：

- 脚本退出码为 `0`
- 第一次返回 `ACCEPTED`
- 第二次返回 `COMPLETED`
- 第三次返回缓存终态 `COMPLETED`

### 3. `test_hold_interrupt.py`

预期：

- 脚本退出码为 `0`
- `FOLLOW_ROUTE` 先返回 `ACCEPTED`
- `HOLD` 返回 `COMPLETED`
- 原任务再次查询返回 `FAILED`
- `error_code=COMMAND_HELD`
